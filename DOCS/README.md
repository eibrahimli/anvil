# Anvil Documentation Map

This documentation set is the consolidated source of truth for product behavior, architecture, and roadmap status.

## Read First
- `DOCS/FOUNDATION.md`: Core philosophy, architecture boundaries, security model, and stack constraints.
- `DOCS/AGENT_WORKFLOW.md`: End-to-end runtime workflow, tool execution flow, approvals, and what users see.
- `DOCS/ROADMAP_STATUS.md`: Consolidated roadmap and active backlog.
- `DOCS/MCP.md`: MCP architecture, configuration, integrations, and test checklist.

## Agent Bootstrap Files
- `.anvil/rules.md`: Compact mandatory rules consumed by agents.
- `.anvil/PLAN.md`: Compact execution snapshot for active work tracking.

## Maintenance Rule
- Add new docs only when they cannot fit one of the files above.
- Avoid phase-by-phase or task-by-task document sprawl; keep status and backlog in `DOCS/ROADMAP_STATUS.md`.
